# Vaishnav Dhanwate — Resume Source

This repository stores the source and exported PDF for a professionally formatted developer résumé.

## Files

| File | Description |
|---|---|
| `Vaishnav Dhanwate1.tex` | LaTeX source used to generate the résumé |
| `Resume_1.pdf` | Exported PDF version |

## Résumé Focus

The LaTeX source presents a web and mobile application developer profile, including:

- Professional objective
- Internship experience
- Technical skills
- Education
- Academic and development projects
- Relevant strengths and credentials

Refer to the source document and PDF for the current résumé content.

## Build the PDF

### Prerequisites
- A LaTeX distribution such as TeX Live or MiKTeX
- Required LaTeX packages referenced in the source (including font, layout, icon and hyperlink packages)

### Compile

From the repository directory, run:

```bash
pdflatex "Vaishnav Dhanwate1.tex"
```

Run the command again if necessary to resolve cross-references and page numbering. Alternatively, open the project in a LaTeX editor such as TeXstudio or Overleaf and compile with pdfLaTeX.

## Updating the Résumé

1. Edit the `.tex` source rather than modifying the PDF directly.
2. Keep contact and profile information current.
3. Recompile the document.
4. Review the generated PDF for formatting and link correctness.
5. Replace the exported PDF when the source is finalized.
